# OpenFDEM Angle-Sensitivity Validation Cases

This folder contains the OpenFDEM calculation input files used for the
screening-angle sensitivity cases discussed in the Cover Letter. The three
subfolders correspond to the minimum intersection-angle settings used to
generate the OpenDFN meshes:

| Folder | Screening angle | OpenFDEM input |
| --- | ---: | --- |
| `angle_10` | 10 degrees | `a10.of` |
| `angle_15` | 15 degrees | `a15.of` |
| `angle_20` | 20 degrees | `a20.of` |

Each subfolder contains:

- the OpenFDEM calculation file (`a10.of`, `a15.of`, or `a20.of`);
- the corresponding Gmsh mesh imported by that calculation (`a10.msh`,
  `a15.msh`, or `a20.msh`); and
- the corresponding OpenDFN input deck (`a10.dfn`, `a15.dfn`, or `a20.dfn`)
  for traceability.

## Running the cases

1. Download and install OpenFDEM from the official OpenFDEM website:
   <https://www.openfdem.com/>.
2. Keep the `.of` and same-name `.msh` file together in the same subfolder.
3. Open each `.of` file with OpenFDEM using the normal OpenFDEM input-file
   workflow. For example, run `angle_10/a10.of`, then repeat for `a15.of` and
   `a20.of`.
4. OpenFDEM will write its result files according to the `of.set.result`
   setting in each input file.

The `.of` files import the same-name `.msh` files directly. Do not rename or
separate these files before running the cases. The `.dfn` files are included as
the OpenDFN source-deck record; OpenFDEM does not import the `.dfn` files
directly in these calculations.

Generated OpenFDEM result files are not included in this upload package. They
can be regenerated by running the three `.of` files. The current `.of` files
use the same material parameters, boundary conditions, and 500000-step
calculation structure as supplied in the original calculation directory.

## Important consistency check

Before submission, confirm that the boundary pressures stated in the Cover
Letter match the values in these `.of` files. The current files specify
30 MPa normal pressure on the left and right boundaries and 10 MPa normal
pressure on the upper and lower boundaries.
